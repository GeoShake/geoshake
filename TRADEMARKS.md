## Modified versions

If you modify the firmware or enclosure and distribute the result, you
must (a) give it a different product name, (b) keep the GeoShake logo off
the enclosure artwork, and (c) retain the copyright notices, license

your derivative must be your own (do not label a modified device as an
official "Rev-C").

## Scope of "open source" for GeoShake

To keep this accurate, please note what is and is not open:

| Part | Status |
|---|---|
| Firmware (incl. DSP reference) | Open — GPL-3.0-or-later |
| Enclosure designs | Open — CC BY-SA 4.0 |
| Documentation | Open — CC BY-SA 4.0 |
| PCB design / schematics | **Proprietary — not published** |
| Cloud backend & network services | **Proprietary — operated by us** |

Because the PCB is proprietary, the device as a whole is **not** open
source hardware, and we ask that it not be described that way. The
accurate description is: *"open source firmware, open enclosure designs,
open data."*
