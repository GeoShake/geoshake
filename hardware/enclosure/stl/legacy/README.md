# Rev-C — superseded

These are the original Rev-C meshes. The current design is **v2.1**, one
directory up: it has the same outer envelope, better RF behaviour, and lid
bosses with a conical lead-in for heat-set inserts.

Print v2.1 unless you are finishing a build you already started on Rev-C, or
you need to match a Rev-C part you have already printed.

| File | Part |
|---|---|
| `Top-Shell.stl` | Lid |
| `Base-T1-Prod.stl` | Base |
| `Wall-Bracket.stl` | Wall bracket — v2.1 calls this the mounting base |

The assembly guide in [`../../docs/`](../../docs/) was drawn for these parts.
