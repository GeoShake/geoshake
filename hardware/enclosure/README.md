**Start here:** print the three STLs with the settings in
[`docs/README.md`](docs/README.md), then follow
[`docs/GeoShake T1 - Assembly Guide.pdf`](docs/GeoShake%20T1%20-%20Assembly%20Guide.pdf).

The Fusion source is published alongside the meshes so the design is
genuinely modifiable, not just printable. If you use another CAD package,
you can export STEP or IGES from the `.f3d`.

## About the top shell

The published top shell is the **production geometry with the engraved
GeoShake wordmark removed**. Retail units differ from these files only by
that engraving, which is a trademark and excluded from the license.

You may print, modify and sell enclosures based on these files. You may
not put the GeoShake name or logo on them — see
[../../TRADEMARKS.md](../../TRADEMARKS.md).

## Scope note

This license covers the **enclosure only**. The GeoShake T1 PCB design is
proprietary and is not published. Please do not describe devices built
from these files as "open source hardware" — the accurate phrasing is
"open enclosure design".
